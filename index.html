あなたのイヤホンが翻訳機に。

AI が先読みする、リアルタイム同時通訳（iPhone）

相手が話している最中から文字にし、Claude（Anthropic の AI）が文の続きを予測しながら前から訳して、イヤホンへ読み上げます。予測が外れたら「いえ、〇〇でした」と自然に言い直します。スラングや専門用語も、前後の会話をふまえて訳します。

  • 話し手が言い終わる前から訳し始める「先読み」同時通訳
  • 雑音を抑えるマイク処理と、話し終わりの自動判定
  • 読み上げが遅れたら、自動で速く・短くして追いつく
  • 用語集で、固有名詞や業界用語の訳語を固定
  • 文字起こしと読み上げは iPhone 内蔵（無料・端末内）または OpenAI を選べる

最初の 1 週間は無料。その後は月額 980 円、または年額 8,800 円のプレミアムで使えます（自分の Anthropic API キーで使うこともできます）。
