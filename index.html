ささやき通訳

イヤホンで聞く、リアルタイムの AI 同時通訳（iPhone）

相手が話している最中から文字にして、文が区切れるたびに Claude（Anthropic の AI）が自然な話し言葉に訳し、イヤホンへ読み上げます。スラングや専門用語も、前後の会話をふまえて訳します。

  • 話しながら認識して、文ごとにすぐ訳す同時通訳方式
  • 雑音を抑えるマイク処理と、話し終わりの自動判定
  • 読み上げが遅れたら、自動で速く・短くして追いつく
  • 用語集で、固有名詞や業界用語の訳語を固定
  • 文字起こしと読み上げは iPhone 内蔵（無料・端末内）または OpenAI を選べる

使うには、Anthropic の API キー（ご自身のアカウント）が必要です。
