あなたのイヤホンが翻訳機に。 プライバシーポリシー

最終更新日: 2026年11月18日（サブスクリプションの追加） ／ 提供者: ITSUKI ASANO

あなたのイヤホンが翻訳機に。（以下「本アプリ」）は、マイクで聞き取った会話をリアルタイムに翻訳し、イヤホンなどへ読み上げる iPhone 用アプリです。このポリシーは、本アプリがどの情報を扱い、どこへ送るかを説明します。

1. 扱う情報

  • マイクの音声（翻訳を開始している間だけ）
  • 音声を文字にした内容（原文）と、その訳文
  • あなたが入力した用語集と設定
  • あなたが登録した API キー（Anthropic、任意で OpenAI。自分のキーで使う場合だけ）
  • プレミアム（サブスクリプション）の購入情報: App Store が発行する署名付きの購入データ（購入 ID、商品、有効期限）。支払い情報は Apple が扱い、提供者は受け取りません。

2. 端末の中で行う処理

  • マイク音声の取り込み、雑音の除去、話の区切りの判定は端末の中で行います。
  • 文字起こし・読み上げに「iPhone 内蔵」を使うときは、Apple が iPhone に用意している音声認識と音声合成を端末の中で使います。音声は外部へ送りません（初回のみ、Apple から言語モデルをダウンロードします）。

3. 外部サービスへの送信

本アプリは、翻訳などの機能のために、次のサービスへ情報を送ります。初めて使う前に、アプリ内でこの送信について同意をいただきます。

提供者の中継サーバー — プレミアム（サブスクリプション）のとき

  • 送る情報: 下の「Anthropic」と同じ翻訳のための情報と、加入を確認するための購入データ
  • 目的: 加入を確認し、提供者の API キーで Anthropic へ翻訳を依頼するため。利用量に上限を設けるため
  • 中継サーバーは Supabase（Supabase Inc.）のサーバー上で動きます。会話の内容は保存しません。保存するのは、購入 ID ごとの月ごとの利用料と利用回数だけです（個人を特定する情報は含みません）。

自分の API キーを使うときは、中継サーバーを通らず、あなたの端末から直接各社へ送ります。

Anthropic（Claude API）— 翻訳

  • 送る情報: 文字にした内容（話している途中の認識結果を含む）、直前の数往復の会話（原文と訳文）、その文ですでに話した訳、用語集、言語の設定
  • 目的: 文脈に合った翻訳文を作るため
  • 取り扱い: Anthropic のプライバシーポリシーと API の利用規約に従います

OpenAI — 文字起こし・読み上げ（使う設定のときだけ）

  • 送る情報: 発話の音声、文字起こしの補助に使う用語集と直前の発話、読み上げる訳文
  • 目的: 音声を文字にするため、訳文を音声にするため
  • OpenAI を使うのは、OpenAI の API キーを登録し、設定で OpenAI（または「自動」）を選んでいるときだけです
  • 取り扱い: OpenAI のプライバシーポリシーと API の利用規約に従います

提供者が受け取るのは、プレミアムで中継サーバーを通る翻訳の依頼だけで、その内容は保存しません。音声と、あなたが登録した API キーを提供者が受け取ることはありません。

4. 端末に保存する情報

  • 設定と用語集: 端末内（アプリの設定領域）に保存します。
  • API キー: 端末の Keychain に保存し、iCloud キーチェーンやバックアップから別の端末へは移りません。
  • 会話のログ（原文と訳文）: アプリを使っている間だけメモリに置き、保存しません。アプリを終了すると消えます。
  • 中継サーバー: 購入 ID ごとの月ごとの利用料と利用回数（公正利用の上限のため）。最後の利用から 13 か月で削除します。

5. 解析・広告・トラッキング

本アプリは、利用状況の解析（アナリティクス）、広告、トラッキングを行いません。これらを目的とする第三者の SDK も含みません。

6. 使う権限

  • マイク: 会話を聞き取って翻訳するために使います。
  • バックグラウンドでのオーディオ: 画面をロックしても翻訳と読み上げを続けるために使います。翻訳を止めると、マイクの使用も止まります。

7. 周りの人の声について

マイクは、会話の相手や周りの人の声も拾い、上の外部サービスへ送られることがあります。会話の相手には翻訳アプリを使っていることを伝え、録音や会話の取り扱いに関する法令を守ってお使いください。

8. 情報の削除

  • API キーは、アプリの設定画面から削除できます。
  • 会話のログは、画面左上のゴミ箱で消せます。アプリを終了しても消えます。
  • アプリを削除すると、端末内の設定と API キーはすべて削除されます。
  • 外部サービスへ送った情報の保存や削除は、各社のポリシーに従います。必要なときは各社へお問い合わせください。

9. お子様の利用

本アプリは、13歳未満のお子様を対象としていません。

10. 変更

本ポリシーを変更するときは、このページを更新し、更新日を書き換えます。送信先や送る情報が変わるときは、アプリ内であらためて同意をいただきます。

Privacy Policy (English summary)

  • What the app handles: microphone audio while translation is running, the transcribed text and its translation, your glossary and settings, and the API keys you register.
  • On-device processing: audio capture, noise reduction and speech segmentation run on the device. With the "on-device" option, Apple's on-device speech recognition and speech synthesis are used and audio does not leave the device.
  • Third parties: using your own API keys, the app sends data directly from your device to (a) Anthropic (Claude API) — the transcribed text, the last few turns of the conversation and your glossary, to translate them; and (b) OpenAI, only if you register an OpenAI key and choose it — the speech audio for transcription and the translated text for speech synthesis. Each provider handles the data under its own privacy policy. The app asks for your consent before first use.
  • Premium relay: with the subscription, translation requests pass through the developer's relay server (hosted on Supabase) to Anthropic, together with the signed App Store purchase data used to confirm the subscription. The relay does not store conversation content; it stores only usage amounts per purchase ID per month for fair-use limits (deleted 13 months after last use). With your own API key, data goes directly from your device to the provider. There is no analytics, advertising or tracking, and no third-party SDK. Payments are handled by Apple.
  • Storage: settings on the device; API keys in the device Keychain (this device only); the conversation log only in memory while the app runs.
  • Bystanders: the microphone may pick up other people's voices. Please tell the people you talk with that you are using a translation app.
  • Children: the app is not directed to children under 13.
