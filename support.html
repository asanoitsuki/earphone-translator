あなたのイヤホンが翻訳機に。 サポート

使い方とよくある質問です。解決しないときは、いちばん下のメールアドレスへご連絡ください。

はじめに

  1. アプリを開いて「先読み同時通訳を1週間無料で」から、プランを選んで始めます。API キーなどの準備はいりません。
  2. 上級者向けに、自分の Anthropic API キーで使うこともできます（設定 > 自分の API キーで使う）。この場合は「文ごと」の翻訳になり、料金は Anthropic からご自身に請求されます。

プレミアム（サブスクリプション）

料金と無料期間

月額 980 円、または年額 8,800 円です。初めての方は最初の 1 週間が無料です。

解約したい

iPhone の 設定 > Apple アカウント > サブスクリプション から解約できます。無料期間中に解約すれば料金はかかりません。

機種変更した・再インストールした

アプリの設定 >「購入を復元」をタップしてください。

「上限に達しました」と出た

サービスを安定して提供するための利用量の上限です（無料期間中は会話で約 2.5 時間、有料期間は毎月約 13 時間が目安）。有料期間は毎月 1 日にリセットされます。

使い方

  1. イヤホンをつなぎ、画面上部で訳す向き（例: 英語 → 日本語）を選びます。
  2. 「翻訳開始」をタップします。初回だけ、音声認識の言語モデルをダウンロードします。
  3. 話し声を聞き取ると、文が区切れるたびに訳をイヤホンへ読み上げます。画面には原文と訳文が残ります。

よくある質問

訳の読み上げが話に追いつかない

設定の「読み上げが遅れたとき」で「いつも要点だけ短く訳す」をオンにしてください。「読み上げ速度」を 1.4〜1.6 倍に上げるのも効果があります。遅れが大きいときは、自動で速く読み、要点だけの訳にし、それでも遅れたら今の話まで飛ばします。

相手の声をうまく聞き取らない

設定の「マイク」を「iPhone マイク」にして、iPhone を相手に向けてください。AirPods などのイヤホンのマイクは、着けている人の声を拾うように作られています。

騒がしい場所で、雑音を話し声と間違える

設定の「発話の区切り」で、「ノイズゲート」と「声とみなす差」を上げてください。

読み上げの声が機械っぽい

iPhone の設定 > アクセシビリティ > 読み上げコンテンツ > 声 から、「拡張」や「プレミアム」の声をダウンロードしてください。アプリはいちばん品質の高い声を自動で使います。

「クレジットが残っていません」と出る

その会社の API の残高がありません。Anthropic は console.anthropic.com、OpenAI は platform.openai.com の Billing でクレジットを購入してください。OpenAI が使えないときは、自動で iPhone 内蔵の文字起こし・読み上げに切り替わります。

自分の API キーで使うときの料金

翻訳に使う Anthropic（と、使う場合は OpenAI）の API 料金が、ご自身のアカウントにかかります。

話した内容はどこへ送られますか

プライバシーポリシーをご覧ください。プレミアムでは提供者の中継サーバーを通って Anthropic に送られます（内容は保存しません）。自分のキーで使うときは、端末からキーを登録した会社へ直接送ります。
