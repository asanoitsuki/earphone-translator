ささやき通訳 サポート

使い方とよくある質問です。解決しないときは、いちばん下のメールアドレスへご連絡ください。

はじめに

  1. console.anthropic.com でアカウントを作り、Billing でクレジットを入れてから、API Keys で sk-ant- で始まるキーを作ります。
  2. アプリの設定（右上の歯車）で、Anthropic のキーを貼り付けて「保存」します。
  3. OpenAI のキーは任意です。なくても、iPhone 内蔵の文字起こしと読み上げで動きます。

使い方

  1. イヤホンをつなぎ、画面上部で訳す向き（例: 英語 → 日本語）を選びます。
  2. 「翻訳開始」をタップします。初回だけ、音声認識の言語モデルをダウンロードします。
  3. 話し声を聞き取ると、文が区切れるたびに訳をイヤホンへ読み上げます。画面には原文と訳文が残ります。

よくある質問

訳の読み上げが話に追いつかない

設定の「読み上げが遅れたとき」で「いつも要点だけ短く訳す」をオンにしてください。「読み上げ速度」を 1.4〜1.6 倍に上げるのも効果があります。遅れが大きいときは、自動で速く読み、要点だけの訳にし、それでも遅れたら今の話まで飛ばします。

相手の声をうまく聞き取らない

設定の「マイク」を「iPhone マイク」にして、iPhone を相手に向けてください。AirPods などのイヤホンのマイクは、着けている人の声を拾うように作られています。

騒がしい場所で、雑音を話し声と間違える

設定の「発話の区切り」で、「ノイズゲート」と「声とみなす差」を上げてください。

読み上げの声が機械っぽい

iPhone の設定 > アクセシビリティ > 読み上げコンテンツ > 声 から、「拡張」や「プレミアム」の声をダウンロードしてください。アプリはいちばん品質の高い声を自動で使います。

「クレジットが残っていません」と出る

その会社の API の残高がありません。Anthropic は console.anthropic.com、OpenAI は platform.openai.com の Billing でクレジットを購入してください。OpenAI が使えないときは、自動で iPhone 内蔵の文字起こし・読み上げに切り替わります。

料金はかかりますか

アプリ自体は無料です。翻訳に使う Anthropic（と、使う場合は OpenAI）の API 料金が、ご自身のアカウントにかかります。

話した内容はどこへ送られますか

プライバシーポリシーをご覧ください。提供者のサーバーはなく、送り先はあなたがキーを登録した会社だけです。
